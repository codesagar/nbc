# Neet & Buddy Chronicles

**[Read online](https://codesagar.github.io/nbc/)** · **[Open the offline reader](Reader/index.html)** — 70 stories, 241 illustrations, and three optional alternate tellings. Open it in a browser, or share the whole `Reader` folder. No installation is needed to read.

For editing, sharing a ZIP, or publishing on GitHub Pages, start with **[the reader guide](Studio/Reader.md)**.

| What you want to do | Where to start |
|---|---|
| Read and browse | [Reader/index.html](Reader/index.html): search, story groups, previous/next, reading preferences and saved progress. |
| Edit a story or find source history | [Stories/README.md](Stories/README.md), the sole maintained story listing. Source Markdown keeps the complete narratives, variants and archival notes. |
| Rebuild the reader | `python3 Studio/build_reader.py` after the one-time setup in [Reader](Studio/Reader.md). |
| Write or illustrate a new episode | [Writing](Studio/Writing.md), [Production](Studio/Production.md), and [Productions](Productions/README.md). |
| Find original character references | [Characters](Characters/README.md) and [reference policies](Characters/reference-policy.json). |
| Explore illustrated acting | [Assets](Assets/README.md): generated pose studies and their limitations. |
| Understand unresolved source choices | [Open Questions](Studio/Open-Questions.md). |
| Preserve, verify or recover work | [Maintenance](Studio/Maintenance.md) and [Recovery](Studio/Recovery.md). |

`Stories/`, `Characters/`, `Assets/` and `Productions/` are the editable library. `Studio/` holds guidance and the small build/verification tools. `Reader/` contains generated browser pages and optimized image copies. Keep it in Git so a clone can be opened immediately; rebuild it after edits. GitHub Pages publishes only that reader folder through the prepared manual workflow.

The expanded collection's reviewed archival edition remains locally at `Productions/Library-Refinement/delivery-v001/`, unchanged. The frozen edition and offline reader ZIP are available in the [archival release](https://github.com/codesagar/nbc/releases/tag/archival-edition-v001). Duplicate frozen folders remain excluded from Git; original external recovery archives remain local. Their own manifests preserve their history independently of active-library accounting.

Original photographs control likeness. N35 excludes anatomy, B08 is styling-only, B25 is unavailable, and B30 is supplemental resting evidence. Generated artwork is interpretation. Style and human likeness remain provisional; the reader cleanup does not grant publication or canon approval. The reader was published on GitHub Pages on October 4, 2026; see the [publication record](Studio/Publication.json). Historical source choices and the failed Night Shift evidence remain documented in the studio.
