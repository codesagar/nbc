Both source images keep their original bytes while receiving descriptive working filenames. Each is a transparent 1536 × 2288 atlas with 8 columns, 11 rows and 192 × 208 cells; row/column counts describe raster organization, not a motion or integration approval. Cells read left to right. In both sheets, the first row contains six resting phases and a separate neutral pose at column 6; rows 1–2 are trots, and rows 9–10 are gaze variants. Neet rows 3–8 show stretch, small hop, lowering to rest, upright head tilt, toy contact and alert sit. Buddy rows 3–8 show paw offer, ball hop, chin lowering, expectant neck lean, ball play and bed yawn. These labels explain how to find a useful pose without a desktop player.

The inspection opened both atlases, both native game run sheets, and beginning/middle/end frames from a Neet stretch, Buddy bed yawn and both runner animations. This supports the curation decision and discloses visible defects. No current live playback, game/desktop integration or final comic style adoption was established. ## Use in a production

Start with eligible original photos, then use a study only to explore acting. Record the selected photo IDs, hashes and complete effective restrictions in the production record. Compare the drawn result with those originals and review the whole reading sequence. Correct fringe, stray pixels and body/face drift before treating any synthetic cutout as final artwork. A historical “approved,” “canonical” or “installed” filename does not supply current owner approval.

Game/desktop installers, binaries, host manifests, helper code, backup packages, duplicate sheets, superseded revisions, failed generation material and inspection caches now belong to the external recovery archive. Their retention there makes them recoverable without making them ordinary NBC assets. No finished environment, prop, lettering or human artwork has been invented to fill empty categories.
